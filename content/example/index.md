# This is the home page of the "example" route

You’re viewing the default page for this route because of the `index.md` file in the `content/example` folder.

You can define additional pages in this route by either:

- creating a Markdown file (e.g. `content/example/file_example.md`), or
- creating a folder containing an `index.md` (e.g. `content/example/folder_example/index.md`).

Both approaches will map to the same URL: `/example/folder_example`.

This allows you to organize your content however works best for you: flat files or nested folders.
